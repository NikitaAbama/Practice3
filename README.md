
# Calculator Practice

Практична робота №3 з Java.

Тема: Обробка виключень у Java.

## Опис програми

Програма реалізує простий калькулятор з чотирма
арифметичними операціями:

- Додавання
- Віднімання
- Множення
- Ділення

Користувач вводить два числа та обирає операцію.

## Обробка виключень

У програмі реалізовано:

- ArithmeticException - ділення на нуль.
- NumberFormatException - некоректне введення числа.
- InvalidInputException - власне виключення для
  некоректних вхідних значень та невідомої операції.

Для обробки помилок використовуються блоки
try-catch-finally.

## Структура проєкту

- Calculator.java - арифметичні операції.
- Main.java - взаємодія з користувачем.
- InvalidInputException.java - власне виключення.
- CalculatorTest.java - тестування калькулятора.
- MainTest.java - тестування введення чисел.

## Використані технології

- Java 21
- Maven
- JUnit 5
- IntelliJ IDEA

## Запуск програми

Відкрити проєкт в IntelliJ IDEA та запустити
метод main() у класі Main.java.

## Тестування

Для запуску тестів відкрити Maven,
вибрати Lifecycle та виконати test.

У проєкті реалізовано 11 автоматичних тестів.
